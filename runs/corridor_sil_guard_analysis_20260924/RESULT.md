# corridor_sil_guard_ab3 负收益机制分析（v2，含勘误）

输入：ab3 两批 6 seeds（31/47/59/71/83/97）× C（纯 PPO）/ S（走廊 SIL + P3.2 优势加权
+ 三道防线 + 1.3 价值校准）双臂的 metrics.csv。
脚本：`analyze_sil_guard.py`（臂间/SIL 内部指标）、`compare_sigma_effect.py`（σ 调度效果）。
数据：`analysis.json`、`sil_internal.png`、`arm_comparison.png`。

> **勘误（v2）**：v1 称"ab3 期间 entropy 钉死 1.51（σ≈0.52）"，系对
> `arm_comparison.png` 的误读。实际 ab3 **两臂**均启用了 σ 调度
> （`ppo_reset_log_std_on_init=True` + 每轮退火 0.02）：entropy 从 -1.64 单调降至
> -2.16（下限），即 σ 全程远小于 0.52 且在退火。v1 的"SIL 在 σ=0.52 下失败"归因
> 不成立，以下结论已全部重写。

## 外部结果（用户报告，复述）

确定性评估 credited 中位数：6 seeds 中 S 臂 4 降 2 微升；探索模式 6/6 全降；
两组"达标并保持 1 秒"均 0/96。整体倾向纯 PPO。

## 训练侧臂间对比

训练采集进度（corridor_progress_m/agent，末 5 轮均值）：S 臂 4/6 更差
（s31: 2.11→1.09，s83: 2.00→1.04，s97: 2.14→0.81）。危害在行为层面，
不只是确定性评估层面。

SIL 内部机制稳定：sil_loss 缓降、weight_mean ≈0.47、pos_frac 单调升至 0.10–0.25、
KL/entropy/n_updates 两臂无系统性差异；行为门控 65/65 轮未跳过（池含 8.1m 种子，
median 恒高于当前行为 → 门控设计上就无法关闭）。**危害来自锚的内容，不是优化不稳定。**

## 新发现：σ 调度本身伤害了纯 PPO

ab3 C 臂（σ 调度）vs formal C 臂（σ≈0.52 钉死）的纯 PPO 对照
（同配方 γ=0.99/λ=0.95、同 init-from 源、同 96k 样本窗口）：

| 组 | 9–11 轮训练进度均值 |
|----|--------------------|
| ab3 C（σ 退火） | **1.68m**（6 seeds 均值） |
| formal C（σ=0.52） | **3.01m**（3 seeds 均值） |

评估侧同向：ab3 C det 中位数 0.055–2.17m，低于 formal C 96k 中期的 2.72–3.83m。
（评估 seed/轮数协议略有差异，训练进度口径更可信；两个口径方向一致。）

**大噪声不是纯粹的信用稀释者，它也是发现引擎。** 在这个硬探索任务里，σ≈0.52 的
OU 噪声通过"幸运远足"实际承担着 frontier 发现职能；退火到 0.08–0.1 后，均值信用
变干净了，但发现量崩塌得更多，净效应为负。M2 诊断（"噪声稀释均值信用"）是对的
但片面——同一噪声的两面性此前只看到一面。

## 修正后的机制结论

1. **SIL 在干净噪声下仍然失败**（ab3 双臂都有 σ 调度）——"噪声污染克隆目标"
   不是主因。剩余候选机制：
   - **结果 ≠ 动作标签**（信用逆问题）：池按结果筛选，但轨迹成功不证明逐步动作
     都该被模仿；这与噪声大小无关，是自模仿的结构性弱点；
   - **状态分布失配/干扰**：精英（尤其 8.1m 种子）所在区域当前策略极少访问，
     共享 backbone 上离线监督干扰在线学习；
   - **预算竞争**：budget_ratio=1.0 时 SIL 与 PPO 各吃等量 minibatch，
     离线梯度剂量过大；
   - 种子 lineage 失配（T_s31 中期 → 当前 C 配方）。
2. **两个"巩固优先"杠杆均被证伪**：SIL（ab3 干净对照）与 σ 下调（ab3 C vs
   formal C）都净负。当前阶段的瓶颈是**发现**，不是巩固。
3. **σ 调度应回退到"继承 checkpoint"**（reset/anneal 关闭）参与后续实验，
   或至少作为独立单变量重新评估——它在 ab3 里与其他改动捆绑，上文的对照
   是在事后分离出来的，强度有限。

## v3 追加：沿"短程没最优"下钻，发现瓶颈在走廊贴合度，且参考线疑似标定偏移

用户质疑"短程都没达到最优"后追加的三个分析（脚本 `fall_locations.py` /
`lateral_deviation.py` / `systematic_offset.py` / `overlay_route.py`，
数据 formal C 臂评估归档 + 参考路线 + 地形多边形）：

1. **进度死亡位置**（`fall_locations.json`）：holdout 峰值投影中位 13.4m、
   末端投影中位 12.2m、回落中位仅 0.77m——**agent 沿路线走得远且大多不跌回
   起点**。"到不了/守不住"不是约束。
2. **横向偏离**（`lateral_deviation.json`，17.1 万帧）：到参考线最近距离中位
   **1.96m**（已超出 1.5m 半径）、p90 4.68m；仅 40.6% 帧在走廊内；出走廊时
   条件中位 3.0m——不是贴边，是**另走一条线**。
3. **系统性偏移**（`systematic_offset.json`）：agent 相对路线最近点的有符号偏移
   均值 **(+0.71, −0.90)m**（x 偏右、y 偏低），叠加 std≈1.8m 的真实散布。
   参考线元数据自带警告："partial_unverified_draft；Pot visual centre is not
   calibrated to the game Player Transform origin"。
4. **决定性可视化**（`route_overlay.png`）：agent 轨迹贴地形表面攀爬，参考线
   系统性悬空于物理路线一侧约 1m——与偏移测量和标定警告三方互证。

**v3.1 修正（用户指出参考线基于 TAS 速通划定后，追加 `route_standoff.py` 检验）**：
参考线每个点到最近地形表面的站立距离剖面显示——**六段每一段都至少有一次
0.34–0.59m 的触地**（≈锅半径 0.4m；若存在 ~1m 常数坐标偏移，地板接触段不可能
贴到这个距离），且全路线最小 0.34m。**坐标标定大概率无显著常数偏移**（元数据
警告属过时/保守），v3 的"修参考线"建议撤回。

偏移是**真实的线路选择差异**：TAS 线站立距离中位 1.82m（大摆飞越、短暂精确
触地），策略贴地爬行（≈锅半径）。"飞"与"爬"是运动学上不同的两种技能，
±1.5m 走廊容不下两条运动学不同的线——这才是 60% 帧在走廊外、credited 被
少计的根源。问题不是"策略没学好 TAS 线"，而是**走廊把两条不同的可行线路
当成了对错**。

## 对优化排序的修订（v3.1，取代 v3）

0. **战略分叉（需用户决策）**：
   - A. 坚持 TAS 线严格走廊：接受能力缺口——但证据表明 OU 噪声策略在运动学上
     可能做不了 TAS 的飞跃触地，长期卡死风险高；
   - B. **自指走廊**：用策略自己的精英轨迹（如 8.1m 那条）构建/滚动更新走廊——
     保留稠密奖励引导，但锚定在运动学可行的线上，精英进步时走廊自动前进；
     与精英池机械天然兼容（池即走廊候选集）；
   - C. 混合：TAS 线作远程/全局宽引导（大半径），精英线作局部精细引导。
   B/C 都能立即让 credited 口径反映"策略在自己线上的真实进展"，消除当前
   3–4m vs 13m 的虚假缺口。
1. 走廊 SIL 维持默认关闭；σ 调度默认回到"继承 checkpoint σ"（均被 ab3
   证伪/拖累，代码保留待复测）。
2. frontier 投放、动作段等学习侧杠杆：排在走廊线路决策之后——走廊口径一变，
   所有历史基线需要重锚。

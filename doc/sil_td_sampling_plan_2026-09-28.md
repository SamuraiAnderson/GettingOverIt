# SIL 精英池采样修改计划：按 (t, D) 覆盖面积分摊

日期：2026-09-28。状态：设计待实现；本次仅更新文档，不修改训练代码、不启动训练。

本计划承接 [v2 计分迁移计划](confirmed_endpoint_progress_v2_plan.md)。沿用 `confirmed_endpoint_v2` 的 t、D、cap 语义和现有 Pareto 归档，修复训练窗口覆盖，并给前沿和非前沿轨迹使用同一套采样优先级。

## 0. 遇到了什么问题

### 0.1 精英池保存了长轨迹，SIL 却只采到了首动作

在 `runs/confirmed_endpoint_v2_formal_20260928_S_s47/elites/elites_iter_0123.npz` 中，有 19 条可比较轨迹，其中 17 条位于 (t, D) 前沿。第一条的有效时间只有 `t=1`，即 `cap=0`。

现有 `equal_traj_window_index()` 先计算 `budget = min(usable_caps) + 1`，再使用 `np.linspace(0, cap, budget)` 选取长轨迹的动作索引。因此本池的预算退化为 1，所有轨迹都只选择 `tau=0`。增大 `sil_td_windows_per_traj` 也无效，因为当前实现仍然取它与最短轨迹预算的较小值。

已经用实际档案重建索引，确认：

- 19 条轨迹生成 19 个窗口，所有窗口的目标动作索引均为 0。
- 按第 123 轮的行为水平门控后保留 11 个窗口，仍全部为首动作。
- `476 步 / 20.1748 米` 和 `800 步 / 24.3565 米` 两条长轨迹的中后段没有进入 SIL 监督。
- 首窗口左填充到 32 步输入长度，不代表学习了后续 32 个动作。

这只影响 PPO 中的 SIL 采样。PPO 仍使用在线采集的完整轨迹；独立模仿脚本直接编码的 1306 个窗口不受该问题影响。

### 0.2 档案最好成绩不等于当前策略已掌握该行为

第 118 到 123 轮的 17 个前沿点相同，最远两点仍为 20.17 米和 24.36 米；同期日志中的在线平均确认进度约为 9.16–9.88 米。

`test_8p_iter0123_desktop` 中已有的 1200 步确定性评估记录显示：8 个 agent 的确认进度为 4.37–10.05 米，结束时 3 个回到路线进度 0，全部未通过该评估的保持判据。该记录只代表一次启动下的这组测试，不是独立重复实验的成功率估计。

另一个独立模仿对照把固定窗口 MSE 从 45.10 降到 16.46，但没有显示出一致的闭环进步。原示范动作重放本身也不稳定，且起点仅核对了部分位置量，不能把所有偏离都归因于物理混沌。当前没有证据支持通过加层或继续追求 MSE 接近零来解决上述问题。

### 0.3 采样优先级必须同时处理时间、距离和非前沿轨迹

新方案需要满足：

- 时间短、距离远都能带来更高采样价值，保持 (t, D) 的双目标含义。
- 两条远距离示范自然得到更多学习机会，不按 rank 名称硬编码倍数。
- 归档保留的非前沿行为补充轨迹仍有合理采样概率，不另设固定预算比例。
- 不让极短轨迹压缩其他轨迹的采样范围，也不让长轨迹仅因窗口多而主导训练。

仅按 `D - 当前平均D` 加权会丢失时间优势；仅按删除单条轨迹后的独占超体积加权，会让全部非前沿轨迹得到零权重。最终采用下文的共同覆盖面积分摊规则。它是明确选择的采样规则，不是 Pareto 定义唯一决定的最优采样分布，学习收益仍需对照验证。

证据文件：

- 训练指标：`runs/confirmed_endpoint_v2_formal_20260928_S_s47/metrics.csv`。
- 确定性评估：`runs/confirmed_endpoint_v2_formal_20260928/test_8p_iter0123_desktop/deterministic_000_agent*.json`。
- 独立模仿对照：`runs/sparse_geometry_20260926/td_v2_rerank/imitation/lr_control_20260927/summary.json` 及其 `game/episodes.json`。
- 采样实现入口：`src/training/sil_archive.py`、`src/training/dataset.py`、`src/training/ppo_trainer.py`。

## 1. 范围与不变量

- 保留现有 (t, D) 支配、去重、距离分桶、容量限制和行为多样性补充规则。只对归档最终保留的轨迹分配训练样本，不把已淘汰轨迹重新纳入。
- 通过现有 `trajectory_endpoint()` / `td_point()` 读取有效性、`t=cap+1` 和确认距离 D，不复制计分逻辑。新模式只接受相同任务、参考线与 v2 口径的可比较轨迹。
- 监督动作范围严格为 `0..cap`；cap 后保留的观察尾段不作为 actor 模仿目标。完整轨迹仍可用于现有回报计算和自举。
- 使用现有 `encode_window()` 构建观测、过去动作、接触信息、稀疏几何和左填充，不改变训练/推理输入语义。
- 本次不改网络、PPO 奖励、SIL 损失公式、相位权重、优势权重、梯度裁剪或优化器。面积只决定采样次数，不再乘进损失。
- 必须同步替换新模式下的单一 D 轨迹门控：不再要求 `D_i > behavior_D_mean * (1 + margin)`。否则短快轨迹会在二维加权前被排除。原行为水平保留作日志；旧模式继续沿用旧门控。
- PPO 对 SIL 的总更新预算约束继续生效；新方案不保证每条轨迹每轮必被抽到。

## 2. 用同一规则计算前沿与非前沿权重

### 2.1 固定时间范围

设任务比较时限为 H，单位为每个 agent 的物理步。当前实验固定为 **1200 步**，取自现有任务的 `steps_per_rollout`，在新实验创建时解析并保存为独立的采样时限。

恢复时使用保存的 H；不能因某轮采集被截短、池内最长轨迹改变或 minibatch 预算变化而自动调整 H。改变 H 属于新实验配置。H 是比较范围，不是某条轨迹的奖励系数。

时间预算取离散整数 `b=1..H`。采用离散定义，是为了让恰好在 `t=H` 达到终点的轨迹仍覆盖最后一个时间预算，而不是因连续积分区间长度为零被忽略。

### 2.2 面积分摊定义

轨迹 i 的点为 `(t_i, D_i)`。在时间预算 b、距离目标 d 下，若 `t_i <= b` 且 `D_i >= d`，该轨迹覆盖这个目标组合。

令 `n(b,d)` 为当前参与分配的轨迹中覆盖该组合的数量，则：

```text
w_i = sum_{b=t_i..H} integral_{d=0..D_i} 1 / n(b,d) dd
p_i = w_i / sum_j(w_j)
```

- 独有区域的面积全部归对应轨迹；共同区域由覆盖它的轨迹均分。
- 非前沿轨迹可以分享共同区域，不需要额外的行为补充权重或前沿/非前沿混合比例。
- 同一有效候选集合中，若 A 严格支配 B，则 A 的分摊面积大于 B；被支配不等于完全没有价值。
- 所有 `w_i` 之和等于包络覆盖区域的总面积，单位为“米·物理步”。改变米/厘米等一致的计量尺度，不改变归一化概率。
- `D<=0`、无效端点或 `t>H` 的轨迹不参与本模式采样；其归档处理沿用原规则。无正面积候选时跳过 SIL，不退回固定首动作。
- 权重使用 float64。概率来自存档点的位置，不使用 `score`、rank 名称、固定加倍系数或额外温度参数。

### 2.3 精确计算，不使用随机估计面积

按全部候选的时间坐标和距离坐标切分矩形区域：

1. 时间切分点为 `1`、所有有效 `t_i`、`H+1`；距离切分点为 `0` 和所有 `D_i`，分别排序去重。
2. 对相邻时间边界 `[a,b)` 和距离边界 `[c,d)`，求覆盖该格的轨迹集合 C。
3. C 非空时，将 `(b-a)*(d-c)/len(C)` 累加到其中每条轨迹。
4. 累加并归一化，检查面积守恒、非负与有限性。

对当前约 20 条轨迹直接枚举即可，不引入网格分辨率、随机面积采样或新的外部依赖。相同档案点的重复计数会改变分摊，因此始终消费已有去重后的池；不能为了增权复制轨迹条目。

### 2.4 当前档案的数值基准

使用第 123 轮全部 19 条可比较轨迹，H=1200，在没有进一步剔除空候选轨迹的情况下，离散覆盖总面积为 **21412.80462645653 米·步**。各代表轨迹的概率为：

- `800 步 / 24.356533 米`：约 **16.4344%**。
- `476 步 / 20.174842 米`：约 **21.5006%**。
- `191 步 / 13.892033 米`：约 **10.8402%**。
- 非前沿 `194 步 / 9.894296 米`：约 **4.1392%**。
- 非前沿 `1026 步 / 17.119965 米`：约 **2.1355%**。
- `1 步 / 0.000778 米`：约 **0.000455%**，不是强行保证每轮一次。

最远两条合计约 37.9350%，非前沿两条合计约 6.2747%。这些是本档案计算结果，不写成配置常量或未来池的目标占比。它们也不表示各条轨迹的闭环成功概率。

## 3. 从轨迹概率到训练窗口

### 3.1 候选准备

数据集为每条有效轨迹保留 `0..cap` 的完整轻量索引，不预先编码全部窗口。删除新模式中“用最短轨迹限制全池索引”的路径。

每轮先在完整候选索引上应用现有接触/空中稀疏保留规则。筛选后没有候选窗口的轨迹退出本轮，并记录原因。再对剩余、满足 H 的候选轨迹计算面积概率，避免把预算分给无法产生窗口的轨迹。保留现有相位损失权重，不把本次修复变成接触权重实验。

### 3.2 总预算

设 N 为本轮正概率轨迹数，K 为每条轨迹对应的平均预算，B 为 batch size，U 为按原规则计算的最大更新次数。本次保持 `sil_epochs=1`，使用：

```text
K = 32（初始计算预算，可配置，不是轨迹权重）
B = 64（沿用当前配置）
S = min(N*K, U*B)
```

U 无上限时取 `S=N*K`；U 为零或没有候选时跳过。N=19 且预算充足时最多 608 个窗口、10 个 batch；PPO 只允许 2 次 SIL 更新时最多 128 个窗口。不能因为候选窗口变多就自动填满 40 次更新。

### 3.3 整数配额

目标配额为 `a_i=S*p_i`。先取 `q_i=floor(a_i)`，再按小数余量做系统重采样，分配剩余 `R=S-sum(q_i)` 个名额：

- 使用独立 RNG 产生 `u in [0,1)`，以 `u, u+1, ..., u+R-1` 命中累计小数余量区间，每次命中增加一个名额。
- R 为零时不产生额外名额。
- 保证配额总和为 S，每条的配额为其目标值的向下或向上取整，且跨轮期望等于 `S*p_i`。
- 不为所有轨迹额外添加“至少一个”的保底，否则会改变已经定义的面积分配。

### 3.4 轨迹内分层随机采样

对轨迹 i，设本轮配额为 q，保留下来的动作索引数为 L：

- q=0：本轮不采。
- q=1：从整个可用区间随机抽一个，不能固定选择起点或终点。
- `1<q<=L`：将按时间排序的候选索引分成 q 个大小尽量相同的连续区间，每区间随机取一个，无重复地覆盖前中后部。
- `q>L`：完整遍历候选索引 `floor(q/L)` 次，再对剩余配额按上述分层方式抽取。允许必要的重复，记录唯一窗口数。

汇合后全局打乱组成 batch，不按轨迹顺序连续训练。使用由训练种子、iteration、SIL epoch 和操作类别派生的独立 RNG；相位筛选、配额取整、轨迹内抽样和打乱使用分开的随机流，不消耗 PPO 动作采样随机流。

### 3.5 与损失衔接

抽样计划形成临时训练视图，保留每个样本到原始 `(trajectory_index, tau)` 的映射。仅编码选中窗口；重复窗口可在本轮复用输入与固定评估结果。

优势/价值目标保留原算法及原可信性触发条件。v2 回报仍沿完整保留轨迹计算，并在原本的结果状态自举；不能把最后一个随机抽到的窗口当作回报终点。面积概率不替代动作优势，也不乘入已有相位/优势损失权重。

如果现有优势门控随后产生零权重，按原规则处理并记录有效样本数，不在本轮自动反复补采直到产生梯度。预算统计采用实际执行次数。

## 4. 配置、兼容与实现位置

新增显式 `sil_td_sampling_mode`，支持：

- `legacy_min_length`：原采样与原 D 门控，供恢复和对照。
- `balanced_stratified`：完整区间内按轨迹均衡分配，用作新方案的对照；与面积模式使用相同候选范围，不启用单一 D 门控。
- `coverage_share`：本计划的面积概率加轨迹内分层随机采样。

新增 `sil_td_sampling_horizon_steps`。新模式创建时若未显式指定，从该实验任务的 `steps_per_rollout` 解析为正整数并保存；恢复只使用保存值。新模式要求 `td_pareto` 和 v2 可比较数据。

复用 `sil_td_windows_per_traj` 作为 K：在两个新模式中正数为 K，0 解析为 32；在旧模式中保留原语义。明确将其描述为总计算预算的平均规模，而不是每条实际固定采样数。

checkpoint、运行配置和诊断文件保存采样模式、解析后的 H/K、采样种子与规则版本。旧 checkpoint 没有字段时恢复为旧模式。切换模式使用显式参数、新运行目录及同一份冻结起点，不静默改变正在恢复的旧实验。

职责划分：

- `sil_archive.py`：候选点的纯函数面积计算、整数配额与轨迹内索引选择；不承担张量编码。
- `dataset.py`：完整候选索引、采样视图到原轨迹的映射，复用原有窗口构建器。
- `ppo_trainer.py`：模式对应的门控、相位筛选、预算和现有损失的衔接。
- 配置与训练入口：参数传递、恢复兼容和独立采样 RNG。

前沿身份可从本轮池重新计算，不依赖目前落盘后可能为 null 的 `archive_role`。本次不顺带修改其他归档元数据语义。

每轮记录模式、H/K、有效轨迹数、空候选数、超出 H 的数量、总覆盖面积、计划与实际窗口数、唯一窗口数、实际更新次数及所用种子。

保存本轮池的标识和实际采样索引，避免只打印“19 个窗口”而无法发现全是 tau=0。单独记录前沿/非前沿实际份额和最高概率轨迹份额，但不将这些统计反过来设成固定配比。

## 6. 离线验证

1. **面积守恒**：所有分摊之和等于独立计算的覆盖面积；概率非负、有限，正面积时总和为 1。全零候选跳过。
2. **前沿/非前沿统一**：构造严格支配对，验证被支配轨迹仍有正面积，支配者面积更大；不使用前沿标签硬编码权重。
3. **边界与单位**：`t=H` 有最后一个预算格的面积，`t>H` 不采；距离整体换单位不改变概率。H 固定，不随池中最大 t 自动改变。
4. **配额期望**：总数恒为 S，单条只取 floor/ceil；用固定种子的多轮纯采样验证长期频率接近目标概率，避免小概率轨迹被确定性舍入永久饿死。
5. **首动作回归**：构造有效长度 1、476、800 的轨迹，验证短轨迹不限制其他轨迹；有足够配额的长轨迹覆盖前中后段，q=1 不恒为零。
6. **窗口边界**：不采 cap 后动作，不引入未来动作；重复样本映射、mask、接触和几何输入一致。
7. **筛选与预算**：相位筛选后为空的轨迹可退出且重新计算面积；零更新预算跳过，部分预算不超限；PPO 随机流不被采样调用改变。
8. **可信回报与恢复**：采样位置改变不改变同一窗口的 v2 回报/自举边界；旧 checkpoint 保持旧模式，新模式恢复后可重现采样计划。
9. **真实档案**：重算第 123 轮 19 条轨迹的第 2.4 节数值，概率绝对误差不超过 `1e-6`；核对远距离轨迹确实出现 tau>0 的中后段窗口。该数值基准在相位随机筛选之前验证。

## 7. 短程训练对照与验收

离线验证通过后，从同一份冻结的 `ppo_iter_0123.pt` 和 `elites_iter_0123.npz` 建立三组新实验，恢复相同优化器状态，训练种子先固定为 47，其他训练配置一致：

- A：原采样和原 D 门控，复现旧路径。
- B：完整区间分层采样，轨迹均衡概率，关闭单一 D 门控。
- C：完整区间分层采样，面积分摊概率，关闭单一 D 门控。

各组新增 **192,000 个物理样本**。B/C 都用 H=1200、K=32、batch=64、SIL epoch=1，并使用相同更新预算上限。A/B 的差异包含采样覆盖、D 门控及实际更新量，不能归因于其中单项；C/B 才用于判断面积优先级的额外价值。

训练结束后，各做 **5 次独立游戏启动，每次 8 个 agent、1200 步确定性评估**，采用相同初始化流程。按启动比较确认进度 D、终点进度、保持成功率、最大回退和前沿变化，不把同次启动中的复制体当作独立重复试验。

功能验收要求离线测试全部通过，并能审计实际中后段覆盖。学习收益另行判断：只有闭环分布改善，才能支持新采样规则有益；降低训练损失、保留远端历史点或增加前沿数量都不单独算作收益。如果 C 未优于 B，保留采样覆盖修复，不宣称面积分摊已经优于均衡采样。

正式扩大训练前，再根据这轮结果决定是否增加独立训练种子。物理不稳定性、示范可靠性和接触观测误差仍是独立问题，不能由采样权重替代解决。

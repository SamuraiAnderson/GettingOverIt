# 游戏输入精度测试方法论

## 📋 文档目的

本文档总结了一套系统化的游戏输入特性测试方法，适用于需要精确了解输入系统行为的场景，特别是：
- 强化学习训练前的环境分析
- 动作空间设计
- 输入预处理设计
- TAS（Tool-Assisted Speedrun）开发

---

## 🎯 核心概念

### 1. 最小有效值（阈值/死区）

**定义**：能产生可观察响应的最小输入值

**特征**：
- 边界特性
- 输入 < 阈值 → 无响应（被滤波）
- 输入 ≥ 阈值 → 有响应

**类比**：门槛高度（需要迈过这个高度才能进门）

**示例**：
```
输入  5 → 无变化 ❌
输入 10 → 有变化 ✓
→ 最小有效值 ≈ 10
```

---

### 2. 输入精度（分辨率）

**定义**：在有效区域内，系统能分辨的最小输入差异

**特征**：
- 内部特性
- 决定动作空间的粒度
- 与最小有效值无关

**类比**：楼梯高度（每阶楼梯的高度）

**示例**：
```
输入 50 vs 51 → 可区分 ✓
输入 50.0 vs 50.1 → 不可区分 ❌
→ 精度 = 1.0（整数）
```

---

### 3. 量化方式

**定义**：系统如何将输入值离散化

**常见类型**：
- **截断（Truncate）**：50.9 → 50
- **四舍五入（Round）**：50.5 → 51
- **上取整（Ceil）**：50.1 → 51

**验证方法**：
```python
测试 50.5:
- 如果行为同50 → 截断
- 如果行为同51 → 四舍五入
```

## ✅ 三阶段测试方案

### 阶段1：粗测 - 确定有效范围

#### 目的
1. 找到最小有效值（死区边界）
2. 找到饱和点（非线性区域）
3. 识别高敏感区域（用于精测）

#### 测试值设计

**方案A：线性采样**（推荐用于已知范围）
```python
test_values = [0, 5, 10, 15, 20, 25, 30, 50, 80, 100]
# 间隔：5-20单位
```

**方案B：指数采样**（推荐用于未知范围）
```python
test_values = [1, 2, 5, 10, 20, 50, 100, 200]
# 2x增长
```

**方案C：自适应采样**（最优但复杂）
```python
# 在响应变化大的区域密集采样
if delta_response > threshold:
    add_intermediate_points()
```

#### 分析方法

**关键指标**：第2帧总变化量（即时响应）

```python
def analyze_immediate_response(csv_path):
    """分析第2帧的即时响应"""
    df = pd.read_csv(csv_path)
    
    # 关键字段
    key_fields = [
        'hammerAngle', 'sliderAngle',  # 角度
        'handleX', 'tipX',              # 位置
        'handleVelX', 'tipVelX',        # 速度
    ]
    
    # 第2帧相对第0帧的变化
    total_change = 0
    for field in key_fields:
        if field in df.columns and len(df) > 2:
            change = abs(df[field].iloc[2] - df[field].iloc[0])
            total_change += change
    
    return total_change
```

**判断标准**：
```python
threshold = 0.01  # 根据实际情况调整

if total_change > threshold:
    status = "有效输入"
else:
    status = "无效输入（死区）"
```

#### 输出结果

1. **死区边界**：首次产生响应的输入值
2. **线性响应区**：响应平稳增长的区间
3. **饱和点**：增长率显著降低的位置
4. **推荐测试区**：用于精测的稳定区域

**示例**：
```
死区：[0, 10)
线性区：[10, 80]
饱和区：[80, ∞)
推荐精测区：50附近（响应稳定且敏感）
```

### 阶段2：整数精测 - 确定整数精度

#### 目的
验证系统能否区分1单位的输入差异

#### 关键原则

**✅ 正确的测试区域选择**：
- 在**响应稳定区**测试（从粗测结果选择）
- 远离死区边界（避免阈值效应）
- 远离饱和区（避免非线性干扰）
- 远离跳跃区（避免异常响应）

**❌ 错误的测试区域**：
```python
# ❌ 在死区边界
test_values = [9, 10, 11, 12]  # 10是阈值，影响结果

# ❌ 跨越死区
test_values = [5, 10, 15, 20]  # 5在死区，10在有效区

# ✅ 在稳定区
test_values = [49, 50, 51, 52]  # 都在线性响应区
```

#### 测试值设计

```python
# 从粗测选择稳定区的中心值
base_value = 50  # 线性区中心

# 生成连续整数序列
test_values = [base_value - 1, base_value, 
               base_value + 1, base_value + 2]
# 例如：[49, 50, 51, 52]
```

#### 分析方法

**可区分性判断**：
```python
def is_distinguishable(value1, value2, threshold=0.01):
    """判断两个输入是否可区分"""
    change1 = analyze_immediate_response(f"result_{value1}.csv")
    change2 = analyze_immediate_response(f"result_{value2}.csv")
    
    diff = abs(change2 - change1)
    is_distinguishable = diff > threshold
    
    return {
        'distinguishable': is_distinguishable,
        'change1': change1,
        'change2': change2,
        'diff': diff,
        'relative_diff': diff / change1 * 100 if change1 > 0 else 0
    }

# 测试所有相邻对
for i in range(len(test_values) - 1):
    result = is_distinguishable(test_values[i], test_values[i+1])
    print(f"{test_values[i]} vs {test_values[i+1]}: "
          f"{'可区分 ✓' if result['distinguishable'] else '不可区分 ✗'}")
```

#### 判断标准

```python
distinguishable_count = sum(1 for pair in pairs if pair['distinguishable'])
total_pairs = len(pairs)

if distinguishable_count == total_pairs:
    conclusion = "精度 ≤ 1.0"
    recommendation = "系统能够分辨1单位差异"
elif distinguishable_count == 0:
    conclusion = "精度 > 1.0"
    recommendation = "需要测试更大间隔（2, 5, 10）"
else:
    conclusion = "精度不均匀或存在噪声"
    recommendation = "检查不可区分对，增加测试样本"
```

## 🔬 关键经验教训

### ❌ 常见错误

#### 错误1：混淆阈值和精度

```
❌ "输入10有效，所以精度是10"

✓  输入10有效 → 最小有效值（阈值）是10
   精度需要在有效区内另外测试
```

**正确理解**：
- 最小有效值 = 门槛高度
- 精度 = 楼梯高度
- 两者独立

#### 错误2：只看累积效果

```
❌ 分析第180帧（3秒后）的状态
   → 包含了大量累积误差和二次效应

✓  分析第2帧（~33ms后）的即时响应
   → 直接反映输入对系统的作用
```

**为什么是第2帧**：
- 第0帧：初始状态
- 第1帧：可能还未完全响应
- 第2帧：输入已作用，响应已显现
- 第3+帧：累积效应开始

#### 错误3：在边界区测试精度

```
❌ 测试 9 vs 10（死区边界）
   → 受阈值效应影响

❌ 测试 5 vs 10（跨越死区）
   → 一个在死区，一个在有效区

✓  测试 49 vs 50（稳定区中心）
   → 都在线性响应区，结果可靠
```

**选择测试区域的原则**：
```python
# 计算距离各种边界的距离
distance_to_dead_zone = test_value - dead_zone_boundary
distance_to_saturation = saturation_point - test_value

# 选择距离足够远的区域
if min(distance_to_dead_zone, distance_to_saturation) > 20:
    suitable_for_precision_test = True
```

#### 错误4：只看单个字段

```
❌ 只检查 playerX 是否变化
   → Player主体可能不动，但锤子在动

✓  看多个关键字段的加权总和
   → hammerAngle, tipX, velocities等
```

**多字段加权方案**：
```python
weights = {
    'hammerAngle': 1.0,      # 角度变化
    'tipX': 10.0,            # 位置变化（放大权重）
    'tipVelX': 5.0,          # 速度变化（中等权重）
}

weighted_change = sum(
    abs(df[field].iloc[2] - df[field].iloc[0]) * weight
    for field, weight in weights.items()
)
```

## 🔧 可复用代码模板

### 完整测试脚本

```python
import pandas as pd
import numpy as np
from pathlib import Path
import subprocess
import shutil
import time

class InputPrecisionTester:
    """输入精度测试器"""
    
    def __init__(self, game_exe, game_data_path):
        self.game_exe = Path(game_exe)
        self.game_data_path = Path(game_data_path)
        self.results = {}
    
    def generate_test_input(self, value, duration_sec=3, fps=60):
        """生成测试输入"""
        n_frames = int(duration_sec * fps)
        commands = []
        for i in range(n_frames):
            commands.append({
                'timestamp': i / fps,
                'mouseXdelta': value,
                'mouseYdelta': 0
            })
        return pd.DataFrame(commands)
    
    def run_test(self, value):
        """运行单个测试"""
        # 生成输入文件
        df = self.generate_test_input(value)
        input_file = self.game_data_path / "input_commands.csv"
        df.to_csv(input_file, index=False)
        
        # 运行游戏
        process = subprocess.Popen([str(self.game_exe)])
        process.wait()
        time.sleep(2)
        
        # 保存结果
        result_file = self.game_data_path / "GameResults" / "ContinuousTracking_latest.csv"
        saved_file = self.game_data_path / "GameResults" / f"result_{int(value):03d}.csv"
        if result_file.exists():
            shutil.copy(result_file, saved_file)
            return True
        return False
    
    def analyze_immediate_response(self, csv_path):
        """分析第2帧响应"""
        df = pd.read_csv(csv_path)
        
        key_fields = ['hammerAngle', 'sliderAngle', 'handleX', 'tipX', 'tipVelX']
        total_change = 0
        
        for field in key_fields:
            if field in df.columns and len(df) > 2:
                change = abs(df[field].iloc[2] - df[field].iloc[0])
                total_change += change
        
        return total_change
    
    def test_coarse(self, test_values):
        """粗测"""
        print("阶段1: 粗测")
        for value in test_values:
            print(f"  测试 {value}...")
            if self.run_test(value):
                response = self.analyze_immediate_response(
                    self.game_data_path / "GameResults" / f"result_{int(value):03d}.csv"
                )
                self.results[value] = response
                print(f"    响应: {response:.6f}")
    
    def test_precision(self, test_values):
        """精度测试"""
        print("\n阶段2: 精度测试")
        for value in test_values:
            print(f"  测试 {value}...")
            if self.run_test(value):
                response = self.analyze_immediate_response(
                    self.game_data_path / "GameResults" / f"result_{int(value):03d}.csv"
                )
                self.results[value] = response
                print(f"    响应: {response:.6f}")
        
        # 分析可区分性
        print("\n可区分性分析:")
        sorted_values = sorted([v for v in test_values if v in self.results])
        for i in range(len(sorted_values) - 1):
            v1, v2 = sorted_values[i], sorted_values[i+1]
            diff = abs(self.results[v2] - self.results[v1])
            status = "✓ 可区分" if diff > 0.01 else "✗ 不可区分"
            print(f"  {v1} vs {v2}: 差异={diff:.6f} {status}")
    
    def generate_report(self):
        """生成报告"""
        print("\n" + "="*60)
        print("测试报告")
        print("="*60)
        print(f"测试数量: {len(self.results)}")
        print(f"结果已保存到: {self.game_data_path}")

# 使用示例
if __name__ == '__main__':
    tester = InputPrecisionTester(
        game_exe="path/to/game.exe",
        game_data_path="path/to/game/data"
    )
    
    # 粗测
    tester.test_coarse([5, 10, 20, 30, 50, 80, 100])
    
    # 精测
    tester.test_precision([49, 50, 51, 52])
    
    # 报告
    tester.generate_report()
```

## 🎯 总结

### 核心要点

1. **区分概念**: 最小有效值 ≠ 精度
2. **看即时响应**: 第2帧，不是累积效果
3. **选稳定区**: 远离边界测试
4. **多维分析**: 不只看单个字段

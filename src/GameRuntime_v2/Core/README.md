# Core - 核心基础设施

> 2026-10-02：批量运行已统一为独立物理世界，当前接口与 reset 契约见[多 player 运行接口](../../../doc/multiplayer_runtime.md)。下文旧复制体/刚体快照流程仅供历史参考。

提供接口定义、事件系统、工具类、配置管理和模式管理。

## 📁 子目录

| 文件夹 | 说明 |
|--------|------|
| **Interfaces/** | 接口定义（所有服务的契约） |
| **Events/** | 事件系统（事件总线和事件常量） |
| **Utilities/** | 工具类（反射、验证、路径、信号文件） |
| **Configuration/** | 配置管理（运行时配置、模式枚举） |

## 📄 核心文件

| 文件 | 说明 |
|------|------|
| **ModeManager.cs** | 模式管理器（三种互斥运行模式） |
| **GameRuntimeManager.cs** | 运行时管理器（统一入口，BepInEx 插件） |
| **ModeManager.md** | 模式管理系统使用文档 |

## 🚀 **快速开始**

### **步骤1: 安装Python依赖**
```bash
# 安装必要的Python包
pip install pandas numpy matplotlib seaborn scipy
# 或者使用requirements.txt
pip install -r requirements.txt
```

### **步骤2: 收集游戏数据**
1. 启动《Getting Over It》游戏
2. 按**F6**启用连续跟踪
3. 按**F7**开始记录
4. 进行游戏操作 (建议2-5分钟)
5. 按**F7**停止记录
6. 按**F8**导出数据到`../TrackingDump/`目录

### **步骤3: 运行数据分析**
```bash
# 快速分析 (30秒内获得结论)
python quick_analysis.py

# 完整分析 (生成详细报告和图表)
python analyze_tracking_data.py
```

## 📊 **数据格式说明**

### **CSV字段详解**
| 字段 | 类型 | 说明 | DOF类别 |
|------|------|------|---------|
| `mouseX` | float | 鼠标X坐标 | 输入DOF-1 |
| `mouseY` | float | 鼠标Y坐标 | 输入DOF-2 |
| `isGripping` | int | 抓握状态(0/1) | 输入DOF-3 |
| `playerX` | float | 玩家X位置 | 状态DOF-1 |
| `playerY` | float | 玩家Y位置 | 状态DOF-2 |
| `velocityX` | float | X方向速度 | 状态DOF-3 |
| `velocityY` | float | Y方向速度 | 状态DOF-4 |
| `hammerAngle` | float | 锤子角度(度) | 状态DOF-5 |
| `hammerAngularVel` | float | 锤子角速度 | 状态DOF-6 |
| `isGrounded` | int | 接地状态(0/1) | 状态DOF-7,8 |
| `timestamp` | float | 时间戳(秒) | 时间维度 |
| `deltaTime` | float | 帧时间差 | 时间维度 |

### **变化率字段**
- `mouseDeltaX/Y` - 鼠标移动变化量
- `grippingChanged` - 抓握状态变化
- `positionDelta` - 位置变化幅度
- `velocityDelta` - 速度变化幅度  
- `angleDelta` - 角度变化量

## 🎯 **分析结论解读**

### **关键指标含义**

#### **控制精度 (0-1)**
- **>0.6**: 优秀 - 输入与状态高度关联
- **0.4-0.6**: 良好 - 控制基本精确
- **0.2-0.4**: 一般 - 需要练习提高
- **<0.2**: 较差 - 控制混乱，需要重新学习

#### **响应性 (0-1)**
- **>0.4**: 优秀 - 输入能快速转化为状态变化
- **0.2-0.4**: 良好 - 响应及时
- **0.1-0.2**: 一般 - 存在延迟
- **<0.1**: 较差 - 反应迟钝

#### **稳定性 (接地比例)**
- **>40%**: 良好 - 能保持稳定状态
- **20-40%**: 一般 - 偶有失控
- **<20%**: 需改进 - 经常失去控制

## 💡 **改进建议解读**

### **常见建议类型**
1. **"提高鼠标精度设置"** - 控制精度<0.4时出现
2. **"增加操作频率"** - 输入活跃度<30%时出现
3. **"提高接地稳定性"** - 接地比例<20%时出现
4. **"延长抓握持续时间"** - 平均抓握<5帧时出现
5. **"优化输入时机"** - 输入-状态相关性<0.2时出现
6. **"练习平滑操作"** - 速度变化过大时出现

### **训练建议实施**
- **精度训练**: 练习缓慢精确移动
- **节奏训练**: 保持连续的微调输入
- **稳定训练**: 延长接地时间，减少空中失控
- **时机训练**: 在合适时机进行输入

## 🚨 **常见问题解决**

### **问题1: 找不到CSV文件**
```
❌ 未找到CSV数据文件
```
**解决方案**:
1. 确保游戏中已按F8导出数据
2. 检查`../TrackingDump/`目录
3. 手动指定文件路径

### **问题2: 依赖包缺失**
```
ModuleNotFoundError: No module named 'pandas'
```
**解决方案**:
```bash
pip install -r requirements.txt
```

### **问题3: 图表无法显示**
- **Windows**: 确保安装了图形界面支持
- **服务器**: 使用`plt.savefig()`保存图片而不是`plt.show()`

### **问题4: 内存不足**
- 限制数据点数量: 只分析最近的N个数据点
- 降低图表分辨率: 修改`dpi=150`

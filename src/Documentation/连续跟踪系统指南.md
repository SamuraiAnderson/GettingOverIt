## 🔬 **自由度分析 (DOF Analysis)**

### **📥 输入自由度 (3 DOF)**
```
1. 鼠标X坐标 (连续值) - 控制锤子水平目标位置
2. 鼠标Y坐标 (连续值) - 控制锤子垂直目标位置  
3. 鼠标左键状态 (布尔值) - 控制抓握/释放
```
**结论**: Getting Over It的输入空间是**3维连续空间**，其中2维是连续的位置控制，1维是离散的动作控制。

### **🎮 最小有效状态集 (8 DOF)**
```
1. Player位置X (连续值) - 玩家水平位置
2. Player位置Y (连续值) - 玩家垂直位置
3. Player速度X (连续值) - 水平速度
4. Player速度Y (连续值) - 垂直速度
5. 锤子相对角度 (连续值) - 锤子相对于Player的角度
6. 锤子角速度 (连续值) - 锤子旋转速度
7. 抓握状态 (布尔值) - 是否正在抓握
8. 接地状态 (布尔值) - 是否接触地面
```
**结论**: 游戏状态空间是**8维混合空间**，包含6维连续状态和2维离散状态。

1. 按**F7**停止记录

## 📈 **数据格式详解**

### **CSV文件结构**
```csv
timestamp,deltaTime,mouseX,mouseY,isGripping,playerX,playerY,velocityX,velocityY,hammerAngle,hammerAngularVel,isGrounded,mouseDeltaX,mouseDeltaY,grippingChanged,positionDelta,velocityDelta,angleDelta

...
```

### **数据字段说明**
| 字段 | 类型 | 范围 | 说明 |
|------|------|------|------|
| **timestamp** | float | 0+ | 游戏时间戳(秒) |
| **deltaTime** | float | 0.01-0.05 | 与上一帧时间差 |
| **mouseX** | float | 0-屏幕宽度 | 鼠标X坐标 |
| **mouseY** | float | 0-屏幕高度 | 鼠标Y坐标 |
| **isGripping** | int | 0/1 | 是否抓握 |
| **playerX** | float | -50~50 | 玩家X位置 |
| **playerY** | float | -10~100 | 玩家Y位置 |
| **velocityX** | float | -20~20 | X方向速度 |
| **velocityY** | float | -20~20 | Y方向速度 |
| **hammerAngle** | float | -180~180 | 锤子角度(度) |
| **hammerAngularVel** | float | -360~360 | 锤子角速度 |
| **isGrounded** | int | 0/1 | 是否接地 |
| **mouseDeltaX** | float | - | 鼠标X变化 |
| **mouseDeltaY** | float | - | 鼠标Y变化 |
| **grippingChanged** | int | 0/1 | 抓握状态是否变化 |
| **positionDelta** | float | 0+ | 位置变化量 |
| **velocityDelta** | float | 0+ | 速度变化量 |
| **angleDelta** | float | -180~180 | 角度变化量 |

## 🎯 **测试验证步骤**

### **第1步：启动游戏并进入场景**
1. 启动《Getting Over It》游戏
2. 进入主游戏界面（看到Player和锤子）
3. 观察左上角插件状态显示

### **第2步：激活监控系统**
```
🎛️ 控制热键：
- F12 - 启用/禁用 State监控（位置、速度、碰撞等）
- F1  - 启用/禁用 Action监控（输入、关节、动画等）
```

### **第3步：验证系统初始化**
观察屏幕左上角状态：
- 应该显示"✅ State监控运行中"
- 应该显示"✅ Action监控运行中"
- 应该显示实时位置和速度数据

### **第4步：执行测试动作并记录**

#### **🎯 基础测试动作序列**：
1. **静止测试** - 保持不动5秒
   - **验证点**: State速度应接近0
   
2. **移动测试** - 按住鼠标左键移动锤子
   - **验证点**: State位置和速度应实时变化
   - **验证点**: Action关节角度应变化
   
3. **释放测试** - 松开鼠标
   - **验证点**: Action抓握状态应从true变false
   
4. **碰撞测试** - 让锤子撞击地面/岩石
   - **验证点**: State应检测到碰撞
   - **验证点**: 速度应突然变化

### **第5步：实时数据验证**
```
🔍 验证命令：
- F2 - 打印当前State详情（控制台查看）
- F3 - 打印当前Action详情（控制台查看）
```

### **第6步：导出数据文件**
```
💾 导出命令：
- F4 - 导出State数据到文件
- F5 - 导出Action数据到文件
```
文件保存位置：
- **State数据**: `../StateDump/PlayerState_[时间戳].txt`
- **Action数据**: `../ActionDump/PlayerAction_[时间戳].txt`

```

3. 每10秒按F4和F5导出数据
4. 检查文件中数据的连续性和合理性
```

### **正常State数值范围**：
- **位置**: X轴 -50~50, Y轴 -10~100（根据地图）
- **速度**: 0~20 单位/秒（正常移动）
- **锤子角度**: -180°~180°（全方位摆动）

### **正常Action数值范围**：
- **关节角度**: -90°~90°（铰链限制）
- **音量**: 0~1.0（Unity标准）
- **抓握距离**: 0.5~2.0单位（手部目标距离）

## 🔧 **故障排除**

### **问题1：监控器未初始化**
- **现象**: 显示"⏳ 监控器未初始化"
- **解决**: 确保在主游戏场景中，重新按F12/F1

### **问题2：数据不更新**
- **现象**: 数值始终不变
- **解决**: 检查是否启用了监控（按F12/F1切换）

### **问题3：控制台无输出**
- **现象**: 按F2/F3无反应
- **解决**: 检查BepInEx控制台是否正常工作

### **问题4：文件无法导出**
- **现象**: 按F4/F5无文件生成
- **解决**: 检查游戏目录写入权限

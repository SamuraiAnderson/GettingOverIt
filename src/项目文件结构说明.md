## 🎮 **Unity 目录 - C# 插件核心**

### **主要文件**
| 文件名 | 功能描述 | 重要程度 |
|--------|----------|----------|
| `GoiHitboxLogger.cs` | 🎯 **主插件入口** - BepInEx插件主类，协调所有功能 | ⭐⭐⭐⭐⭐ |
| `GoiHitboxLogger.csproj` | 🔧 **项目配置** - 编译设置、依赖引用、构建规则 | ⭐⭐⭐⭐⭐ |

### **监控系统**
| 文件名 | 功能描述 | 重要程度 |
|--------|----------|----------|
| `StateMonitor.cs` | 📊 **状态监控** - 监控Player位置、速度、碰撞等最终状态 | ⭐⭐⭐⭐ |
| `ActionMonitor.cs` | 🎛️ **动作监控** - 监控输入、关节、动画等控制状态 | ⭐⭐⭐⭐ |
| `ContinuousTracker.cs` | 🔄 **连续跟踪** - 高频采样连续记录游戏数据 | ⭐⭐⭐⭐⭐ |

### **数据收集器**
| 文件名 | 功能描述 | 重要程度 |
|--------|----------|----------|
| `HitboxCollector.cs` | 💥 **碰撞体收集** - 收集Mountain下所有PolygonCollider2D | ⭐⭐⭐ |
| `PlayerAnalyzer.cs` | 🔍 **Player分析** - 递归分析Player对象完整结构 | ⭐⭐⭐ |

### **编译说明**
```bash
# 进入Unity目录
cd Unity/

# 编译项目
& "C:\Program Files (x86)\Microsoft Visual Studio\2019\BuildTools\MSBuild\Current\Bin\MSBuild.exe" GoiHitboxLogger.csproj /p:Configuration=Release

# 自动部署到游戏目录
# 编译后会自动复制DLL到: [游戏目录]\BepInEx\plugins\
```

## 🐍 **Python 目录 - 数据分析系统**

### **分析脚本**
| 文件名 | 功能描述 | 使用场景 |
|--------|----------|----------|
| `quick_analysis.py` | ⚡ **快速分析** - 30秒内输出核心结论 | 日常快速检查 |
| `analyze_tracking_data.py` | 🔬 **完整分析** - 生成12个图表和详细报告 | 深度分析研究 |
| `generate_sample_data.py` | 🧪 **示例数据** - 生成测试数据验证分析脚本 | 开发测试 |

### **使用方法**
```bash
# 激活Python环境
conda activate getting-over-it-analysis

# 进入Python目录
cd Python/

# 快速分析 (推荐)
python quick_analysis.py

# 完整分析 (生成图表)
python analyze_tracking_data.py

# 生成测试数据
python generate_sample_data.py
```

### **功能特点**
- **自动检测CSV文件** - 自动选择最新的数据文件
- **3DOF输入分析** - 鼠标轨迹、抓握模式、操作强度
- **8DOF状态分析** - 位置、速度、角度、接地状态
- **关联性分析** - 输入与状态的响应关系
- **操作评价** - 控制精度、响应性、稳定性评级

## ⚙️ **Environment 目录 - 环境配置**

### **Conda 环境配置**
| 文件名 | 功能描述 | 平台 |
|--------|----------|------|
| `environment.yml` | 📦 **Conda环境定义** - 包依赖和版本规范 | 跨平台 |
| `setup_conda_env.bat` | 🚀 **Windows安装脚本** - 一键创建环境 | Windows |
| `setup_conda_env.sh` | 🚀 **Linux/Mac安装脚本** - 一键创建环境 | Linux/Mac |
| `requirements.txt` | 📋 **Pip依赖列表** - Python包依赖 | 跨平台 |

### **环境设置流程**
```bash
# 方法1: 使用自动脚本 (推荐)
# Windows:
cd Environment/
setup_conda_env.bat

# Linux/Mac:
cd Environment/
chmod +x setup_conda_env.sh
./setup_conda_env.sh

# 方法2: 手动设置
conda env create -f environment.yml
conda activate getting-over-it-analysis
```

### **依赖包说明**
- **pandas**: CSV数据读取和处理
- **numpy**: 数值计算和数组操作
- **matplotlib**: 基础图表绘制
- **seaborn**: 统计图表和热图
- **scipy**: 峰值检测和科学计算

## 🎯 **项目特点总结**

### **🔬 科学性**
- **定量分析**: 3DOF输入 + 8DOF状态的完整数据空间
- **统计评估**: 相关性分析、峰值检测、分布分析
- **可视化**: 12种专业图表展示多维数据

### **🚀 易用性**
- **一键安装**: 自动化环境配置脚本
- **热键操作**: F6-F9游戏内快速操作
- **自动检测**: Python脚本自动找到最新数据

### **⚡ 高效性**
- **高频采样**: 50Hz连续记录，无遗漏
- **精简参数**: 最小有效参数集，避免冗余
- **快速分析**: 30秒内获得核心结论

### **🔧 可扩展性**
- **模块化设计**: Unity监控器独立，Python分析器独立
- **标准格式**: CSV数据便于第三方工具分析
- **开源架构**: 完整源码，可自定义扩展
